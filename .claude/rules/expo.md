# Expo (mobile) context active

## Before writing any code

Load `docs/standards/frontend.md` + `docs/standards/frontend-mobile.md` for the task.

## New feature? Use the scaffold script first

```bash
npm run scaffold:frontend -- --feature <kebab-name> --app expo
```

Generates failures, datasource, hooks, screen, i18n stub, and README. Fill in domain logic only.

## Architecture rule (never break)

```text
Screen → Hook → Datasource → Proxy → apiClient
```

- Screens render UI, compose hooks — never import datasources directly
- Hooks wrap `useQuery` / `useMutation` — never call proxy functions directly
- Datasources call proxy functions and translate errors to typed Failures
- Proxy is auto-generated by Orval — never hand-edit files in `src/proxy/`

## After generating or modifying proxy usage

```bash
npm run generate:proxy        # fetch schema + regenerate
npm run generate:proxy:local  # use committed schema only
```

## Styling

- Tailwind v4 via Uniwind — `className` prop, not `style`
- Design tokens from `@starterkit/shared/tokens.css` + `constants/tokens.ts`
- Never hardcode colours — use semantic token classes (`bg-primary`, `text-secondary`, etc.)

## i18n

- All user-facing strings via `useTranslation('<namespace>')`
- Never hardcode English text in components
- Add new namespace to `src/lib/i18n/index.ts` and `i18n.d.ts`
- Locale values: sentence-case only (`npm run check:locale-casing` enforces this)
